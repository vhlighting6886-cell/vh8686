# Bản gom nhóm gọn

Màn bán hàng nhanh chỉ nhập nhóm sản phẩm, hiện danh sách sản phẩm trong nhóm giống ảnh mẫu.

Cách dùng:
1. Chạy `database/PATCH_GOM_NHOM_GON.sql` trong Supabase SQL Editor.
2. Upload toàn bộ thư mục này lên GitHub.
3. Vercel Redeploy và chọn Clear Build Cache.

Dấu nhận biết đúng bản: trong Bán hàng nhanh có nhãn `BẢN GOM NHÓM GỌN`.
