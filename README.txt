Bản sửa PDF/QR:
- QR đã nhúng base64 trực tiếp trong code, không phụ thuộc file online.
- Sản phẩm in hóa đơn chỉ hiện nhóm và tên, không in link Vercel.
- Khi bấm In, code chờ QR decode rồi mới mở hộp thoại in.

Cách dùng:
1. Thay toàn bộ file trong repo bằng bản này.
2. Vercel > Redeploy > Clear Build Cache.
3. Mở tab ẩn danh test lại.
