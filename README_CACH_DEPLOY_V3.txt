BẢN GOM NHÓM V3 - CODE LẠI

1) Vào Supabase > SQL Editor, chạy file:
   database/PATCH_GOM_NHOM_V3.sql

2) Upload TOÀN BỘ thư mục này lên GitHub, thay hết file cũ.

3) Vào Vercel > Project > Deployments > Redeploy > tích Clear Build Cache.

4) Mở tab ẩn danh kiểm tra. Nếu đúng bản, màn hình bán hàng sẽ hiện:
   BẢN GOM NHÓM V3 - CODE LẠI

Bản này sửa:
- Bán hàng nhanh gõ nhóm sản phẩm, hiển thị sản phẩm trong nhóm.
- Không dùng dropdown sản phẩm bị lặp như bản cũ.
- Trùng nhóm + tên thì cập nhật sản phẩm, không báo duplicate.
- Số lượng và tiền nhập ổn định hơn, hỗ trợ nhập 75000 hoặc 75.000.
